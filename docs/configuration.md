# Configuration

SessionFlipper stores its configuration in:

```text
~/.config/sessionflipper/config.yaml
```

The configuration consists of three parts:

- General preferences
- Display profiles
- Automatic switching

---

# Session priority

The session priority is only used when more than one configured display profile
matches the current display configuration.

The session listed first has higher priority.

Example:

```
Desktop > Console
```

If both a Desktop profile and a Console profile match, SessionFlipper selects
Desktop.

---

# display_settle_time

`display_settle_time` specifies how long SessionFlipper waits after receiving a
DRM hotplug event before reading the current display configuration.

Some systems require a short delay until the DRM subsystem reports the final
display state.

Recommended value:

```
0.1
```

Increase this value only if displays are detected unreliably.

---

# debounce_time

After display detection has completed, SessionFlipper waits for
`debounce_time`.

During this time, DRM hotplug events generated by the session switch itself
(for example by restarting SDDM) are allowed to accumulate.

After the timeout expires, all queued events are discarded before waiting for
the next real hotplug event.

This prevents repeated session detection caused by the session switch itself.

Recommended value:

```
3.0
```

---

# Display profiles

Each display profile consists of:

- display fingerprint
- display name
- target session

Example:

```
Office Monitor -> Desktop
TV -> Console
Steam Deck only -> Console
```

When the current display configuration matches a configured profile,
SessionFlipper automatically switches to the associated session.
