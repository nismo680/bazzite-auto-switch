# SessionFlipper

> Automatic Desktop ↔ Console session switching for Linux systems using `steamos-session-select`.

![Python](https://img.shields.io/badge/Python-3.12+-3776AB?logo=python&logoColor=white)
![Linux](https://img.shields.io/badge/Linux-systemd-FCC624?logo=linux&logoColor=black)
![Status](https://img.shields.io/badge/Status-Active%20Development-orange)
![License](https://img.shields.io/badge/License-MIT-green)

Automatically switches between **Desktop** and **Console** whenever your display
configuration changes.

No polling. No root privileges. Easy to use.

---

## Why?

If you regularly connect and disconnect

- a docking station
- an external monitor
- a TV

you probably switch manually between

- 🎮 Console Mode
- 🖥 Desktop Mode

SessionFlipper does this automatically.

---

## Features

- ⚡ DRM hotplug event detection
- 🚫 No polling
- 🎮 Uses the official `steamos-session-select`
- 🖥 Automatic Desktop ↔ Console switching
- ⚙ Configurable display profiles
- ⏱ Configurable settle delay
- 🧹 Automatic DRM event cleanup
- 🔧 systemd user service *(coming soon)*
- 🔒 No root or sudo required
- 🐬 KDE tray application *(coming soon)*

## Installation

```bash
git clone https://github.com/nismo680/sessionflipper.git

cd sessionflipper

python -m venv .venv

source .venv/bin/activate

pip install -e ".[dev]"
```

---

## Quick Start

Configure your display profiles.

```bash
sessionflipper displays
```

Configure priority, settle and debounce time.

```bash
sessionflipper settings
```

Run the daemon

```bash
sessionflipper daemon
```

## Commands

| Command | Description |
|---------|-------------|
| `sessionflipper list` | List detected displays |
| `sessionflipper displays` | Configure display profiles |
| `sessionflipper settings` | Configure settings |
| `sessionflipper config` | Show configuration |
| `sessionflipper status` | Show current status |
| `sessionflipper enable` | Enable automatic switching |
| `sessionflipper disable` | Disable automatic switching |
| `sessionflipper daemon` | Run in foreground |

## How it works

Linux generates a DRM hotplug event whenever a display is connected or disconnected.

SessionFlipper waits for the configured `display_settle_time`, allowing the DRM subsystem to reach a stable display state.

It then detects the active display configuration, matches it against the configured profiles and switches to the appropriate session using `steamos-session-select`.

After the detection has finished, SessionFlipper waits for the configured `debounce_time` and discards any queued DRM events generated by the session switch itself (for example by restarting SDDM).

This prevents unnecessary repeated display detection while remaining completely event-driven.
